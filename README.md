# Android Midterm Toolkit - Phatthida Dokngam (67102122123)

This repository contains the source code for the Android Programming Midterm Project.

## Features Implemented:
1. **Student Profile Screen**: Displays student information, photo, and stylized custom toolkit panels.
2. **Interactive Map Screen**: Uses `osmdroid` for geographical location services and interactive markers.
3. **Installment Calculator Screen**: Full MVVM implementation for multi-tier interest rate loan calculations.
4. **Lifecycle Demonstration**: Fully integrated Toast and Logcat alerts for tracking Android Activity Foreground Journey.
